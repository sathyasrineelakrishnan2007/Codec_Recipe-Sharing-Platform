Recipe Sharing Platform 🍲

Project Description

The Recipe Sharing Platform is a simple application that allows users to explore and share their favorite recipes. It helps users learn about different dishes and their preparation methods.

Objectives

- To create a simple recipe-sharing application.
- To display recipe names and ingredients.
- To provide cooking instructions.
- To encourage users to explore different recipes.

Technologies Used

- Java

Features

- Displays recipe details.
- Shows ingredients required for cooking.
- Provides step-by-step cooking instructions.
- Simple and beginner-friendly application.

How to Run

1. Install Java JDK.

2. Save the Java code as "RecipeSharing.java".

3. Open the terminal in the project folder.

4. Compile the program:
   
   "javac RecipeSharing.java"

5. Run the program:
   
   "java RecipeSharing"
